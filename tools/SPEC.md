# 영어 어휘 데이터 작성 규칙 (한 파일 = 한 레벨 × 한 알파벳 구간, 단어 50개)

파일 형식(그대로):

```js
(window.WORDS = window.WORDS || []).push(
  {
    w: "achieve", lv: "중급", pos: "동사 · achievement(명사)", ph: "/əˈtʃiːv/",
    mean: "(노력 끝에) 이루다, 달성하다",
    parts: [["a-", "~쪽으로"], ["chieve", "끝(chef)에 이르다"]],
    easy: "쉬운 설명 2~3문장(한국어). 어원·연상법·기억 장치 포함.",
    img: "장면으로 떠올리기 1문장(한국어).",
    nuance: "뉘앙스·혼동 단어·문법 패턴·주의점 1~2문장(한국어).",
    colloc: ["achieve a goal", "achieve success", "achieve results"],
    syn: ["accomplish", "attain", "reach"], ant: ["fail"],
    s: [
      ["She worked hard to [[achieve]] her dream.", "그녀는 꿈을 이루려고 열심히 노력했다.", "일상"],
      ["...", "...", "뉴스"],
      ["...", "...", "학교"],
      ["...", "...", "대화"]
    ]
  },
  { ... }
);
```

규칙
- w: 소문자 한 단어(구·대문자·하이픈 금지). 표제어 철자는 예문의 [[ ]] 안과 **정확히 같아야** 한다(활용형 금지). 문장을 to부정사·조동사·복수 주어·명사 단수 등으로 설계해 원형이 그대로 들어가게 쓴다. 한 문장에 [[ ]]는 정확히 1개.
- lv: "중급" 또는 "고급" (파일 지정대로).
  - 중급 = 한국 중학교 교과서·내신 핵심 단어(너무 쉬운 apple/book 류 제외, 중1~중3 수준).
  - 고급 = 중3~고1·수능 초입 수준의 어려운 단어(중급 파일과 겹치지 않도록 확실히 더 어려운 단어).
- pos: 한국어 품사 + 대표 파생어(영어) 예: "명사 · 형용사형 vital", 없으면 품사만. 품사가 여러 개면 가장 흔한 쓰임을 앞에.
- ph: 미국식 IPA를 /…/로. 정확히 모를 단어는 고르지 말 것.
- mean: 한국어 뜻(핵심 뜻 1~2개, 간결하게).
- parts: 접두사·어근·접미사 분해 [[요소, 한국어 뜻], …] (2~3개). 분해가 학습에 도움 안 되면 빈 배열 [] (전체의 약 40%는 채우기).
- colloc: 3개 이상, 각 항목에 표제어가 철자 그대로 포함된 자연스러운 영어 표현.
- syn: 영어 유의어 2~3개(표제어와 같은 단어 금지), ant: 영어 반의어 0~2개(없으면 []).
- s: 정확히 4문장. [영어 예문, 한국어 번역, 쓰임 맥락]. 맥락 라벨은 짧은 한국어(일상/뉴스/학교/대화/설명문/논설/서사/과학/경제/조언 등)로 4개를 서로 다르게. 예문은 서로 다른 장면·문형으로 자연스럽게, 15단어 안팎. 중급은 쉬운 문장, 고급은 약간 긴 문장.
- 한자(漢字) 사용 금지. 개인정보·특정 인물·민감한 주제 금지. 설명은 중학생이 읽는 쉬운 한국어.
- 내용은 정확해야 한다(뜻·품사·발음·어원). 어원이 불확실하면 연상법만 쓰고 단정하지 말 것.
